# 🌍 Land Classification using CNN + Vision Transformer (ViT)

This project demonstrates **land classification** using a hybrid approach that integrates **Convolutional Neural Networks (CNNs)** and **Vision Transformers (ViTs)**.  
It was developed as part of the IBM AI Engineering Professional Certificate coursework.

---

## 📌 Project Overview
- Implemented land classification pipeline using both **TensorFlow/Keras** and **PyTorch** frameworks.  
- Compared the effectiveness of **CNNs** (great for local feature extraction) and **ViTs** (effective for capturing global dependencies).  
- Provides a clean, end-to-end workflow: **data preprocessing → model training → evaluation**.

---

## ⚙️ Tech Stack
- **Languages**: Python  
- **Frameworks**: TensorFlow/Keras, PyTorch, Hugging Face Transformers  
- **Libraries**: NumPy, Pandas, Matplotlib, scikit-learn  

---

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/ai-land-classification-cnn-vit.git
   cd ai-land-classification-cnn-vit
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the Jupyter Notebook:
   ```bash
   jupyter notebook Land_Classification_CNN_ViT_Cleaned.ipynb
   ```

## 📊 Results & Key Insights
- CNNs capture **local spatial features** well.  
- ViTs capture **global dependencies**.  
- A hybrid approach (CNN + ViT) can enhance classification performance.
